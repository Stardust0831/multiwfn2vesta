# Skill: Multiwfn Surface Extrema to VESTA

Use this when Multiwfn molecular surface analysis has produced
`surfanalysis.pdb` and the extrema should be shown on a VESTA mapped surface.

## Source Convention

Multiwfn main function `12` surface-analysis post-processing menu can export
`surfanalysis.pdb`.  In `surfana.f90`, menu item `2` writes the file.  The
source comment and output message state the convention:

- `C`: surface maximum
- `O`: surface minimum
- PDB B-factor: mapped function value, with unit reported by REMARK when
  Multiwfn knows it
- optional `CRYST1`: written for periodic systems

Bundled VMD scripts use this file for mapped surfaces:

- `molsurfmap.vmd`: loads `surfanalysis.pdb` if present
- `ALIE.vmd`: shows `name O`
- `LEA_isoext.vmd`: shows `name C`
- `LEAE_isoext.vmd`: shows `name O`

## Maintained Commands

Generate a mapped surface and extrema overlay in one step:

```bash
multiwfn2vesta cube-preset surface-map density.cub products \
  --texture-cube mapped.cub \
  --surfanalysis-pdb surfanalysis.pdb \
  --surf-extrema all
```

ALIE/LEA/LEAE auto-selection:

```bash
multiwfn2vesta cube-preset alie density.cub products \
  --texture-cube avglocion.cub \
  --surfanalysis-pdb surfanalysis.pdb

multiwfn2vesta cube-preset lea density.cub products \
  --texture-cube userfunc.cub \
  --surfanalysis-pdb surfanalysis.pdb
```

With `--surf-extrema auto`, `alie` and `leae` show minima, `lea` shows maxima,
and other mapped-surface presets show all extrema.  Override with
`--surf-extrema all|maxima|minima`.

Patch an existing VESTA file:

```bash
multiwfn2vesta surface-extrema input.vesta surfanalysis.pdb output.vesta \
  --surface-cube density.cub \
  --selection all
```

## VESTA Behavior

- The overlay is embedded as a new atoms-only phase before `SCENE`; VESTA does
  not need to load the PDB separately.
- Coordinates from `surfanalysis.pdb` are Angstrom coordinates.  The tool
  shifts them by the cube origin so they align with VESTA's cube frame, then
  writes molecule or crystal coordinates using the same cube summary logic as
  `cube-vesta`.
- The overlay phase has empty `SBOND`, so extrema are not connected by bonds.
- The command patches an existing `COMPS` line to `COMPS 0` by default after
  adding an extra phase.  Files generated by `cube-preset` contain this line.
- Default style is radius `0.10`, maxima red, minima blue.  Use
  `cube-preset --extrema-radius` or standalone `surface-extrema --radius`
  plus `--maxima-rgb`, `--minima-rgb`, and `--label-extrema` for
  figure-specific tuning.
- `surface-extrema` appends a new extrema phase each time it is run.  Start
  from the unpatched source file when regenerating an overlay; a future
  `--replace-existing` mode can make this idempotent if needed.
- `CRYST1` is parsed for provenance, but the maintained coordinate alignment
  uses the supplied `--surface-cube`.  Keep `surfanalysis.pdb` and the cube
  from the same Multiwfn surface-analysis run.
