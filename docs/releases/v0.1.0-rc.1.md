# v0.1.0-rc.1 Prerelease Notes

This prerelease previews the human-facing stable tools layer for
`multiwfn2vesta`.  It is not a full scientific workflow guarantee and does not
bundle Multiwfn, VESTA, ABACUS, or platform-specific executables.

## Main Entry Points

```bash
multiwfn2vesta tools --lang en
multiwfn2vesta tools --lang zh
multiwfn2vesta tools interactive --lang zh
multiwfn2vesta tools run <tool> -- <args>
```

`tools interactive` is a number-driven chooser.  It asks for input files,
output files/directories, and common options, then prints the assembled
arguments and asks for confirmation before running.

## Known Limits

- VESTA GUI rendering/no-focus rendering is still environment-sensitive and is
  not promoted as a stable tool in this prerelease.
- ABACUS LR conversion is stable only for the tested single-rank/Gamma-style
  bridge.
- Multi-rank/multi-k ABACUS excitation conversion and risky ABACUS GPU/PW
  direct-cube paths remain experimental.
- Release artifacts are source archive/tag based; no standalone executable is
  bundled yet.
